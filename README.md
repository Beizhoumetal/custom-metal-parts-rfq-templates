# Custom Metal Parts RFQ Templates & Buyer Checklists

Practical, non-confidential templates and pre-quote checklists for mechanical engineers, sourcing managers, and buyers preparing Request for Quotation (RFQ) packages for custom metal components.

> **Before sharing proprietary CAD files or 2D drawings:** Start with a non-confidential summary first (process family, general part description, alloy/thickness if selected, target quantity, and destination). Confirm confidentiality terms, named manufacturing recipients, and a secure file-transfer channel before sending sensitive engineering documents.

## Copy-Ready Non-Confidential RFQ Snippets

### 1. CNC Machining (Quote Scope Alignment)

```text
Process: CNC machining
Part summary: [PART TYPE / FUNCTION]
Drawing / model status: Revision [REV] (units: [MM / INCH]; drawing governs)
Material & condition: [ALLOY / GRADE / TEMPER]
Quantities: [PROTOTYPE / INITIAL LOT / REPEAT ESTIMATE]
Critical tolerances & finish: [KEY BORES / DATUMS / THREADS; ANODIZING OR MASKING IF ANY]
Inspection needs: [SAMPLE REPORT / CRITICAL FEATURES ONLY]
Destination & target window: [COUNTRY / DATES]

Please confirm one-time setup or fixture charges separately from unit pricing and list any excluded operations or proposed material substitutions before quoting.
Non-confidential summary only; please confirm confidential transfer arrangements before drawings are sent.
```

### 2. Sheet Metal Fabrication (Cutting, Bending, Finishing)

```text
Process: Sheet metal fabrication
Revision & material: [REV / GRADE / THICKNESS]
Operations required: [CUTTING / BENDING / HARDWARE / WELDING / FINISH]
Quantities: [INITIAL / REPEAT ESTIMATE]
Inspection & packing: [KEY FORMED DIMENSIONS / COSMETIC FACE / PROTECTIVE PACKING]
Destination & target window: [COUNTRY / DATES]

Please separate one-time setup or tooling charges from unit prices, state bending/hardware assumptions, and list any excluded secondary processes.
```

### 3. Metal Stamping (Tooling & First Article Alignment)

```text
Process: Metal stamping
Revision & material: [REV / GRADE / CONDITION / THICKNESS]
Demand profile: [TRYOUT / INITIAL ORDER / ANNUAL PLANNING ESTIMATE]
Tooling scope: [PROPOSED CONCEPT / OWNERSHIP / STORAGE / MAINTENANCE TERMS]
Edge & FAI requirements: [CRITICAL EDGES OR OPENINGS / SAMPLE FAI SCOPE]
Destination & timing: [COUNTRY / TARGET DATES]

Please quote tooling, tryout, and recurring unit charges separately and list all exclusions.
```
